# Formula-1-Race-Analyzer
A python project that analyzes F1 races and any driver of your choice ( Still working on it)
#What it does
The analyzer allows users to examine Formula 1 race data, including:

- Driver positions
- Position changes
- Lap times
- Driver speeds
- Race performance
- Overall race ratings

I made use of Python, FastF1, pandas and Matplotlib
Will be improving it over time and I do wish to get recognized by Formula 1.
